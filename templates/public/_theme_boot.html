{% comment %} One theme for the whole product, decided before the first paint. The student app keeps its choice in localStorage['lumen-theme'] ("dark", "light", or absent for "follow the system"). These pages used to keep their own key, 'epcai-theme', so a student who chose dark in the app met a white sign-in page. The app's key is read first, the old key second, the system setting last; a toggle here writes both, so the choice is the same wherever it was made. The resolved theme lands on twice: as the `dark` class the Tailwind pages style against, and as data-theme, which the standalone sign-in card styles against. Included in by base/design.html and auth/_epc_auth.html; it must stay a plain inline script so nothing can paint before it runs. {% endcomment %}
