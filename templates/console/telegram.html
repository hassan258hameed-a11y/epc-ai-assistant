Setup guide

Once, in this order. Takes about ten minutes.

  1. Create the bot. In Telegram, open @BotFather, send /newbot, give it a name (e.g. “EPC AI Assistant”) and a username ending in bot. BotFather replies with the token — treat it like a password.
  2. Menu and privacy. Press Set command menu above (or send BotFather /setcommands with the list on the right). Leave /setprivacy enabled — the bot only needs commands, never group chatter, and privacy mode doesn't stop it posting to the community group.
  3. Create the channel. New Channel, then give it the name students will see. Public gives it a @username and a t.me link; private gives it a numeric id starting -100.
  4. Make the bot an administrator. Channel → Administrators → Add admin → your bot, with Post messages on. That also lets it delete its own posts when you retract an announcement — Telegram allows that for 48 hours; Delete messages is optional. Once the bot is added, this page shows the channel's id under “Detected”.
  5. Create the community group (optional). New Group → e.g. “AI Assistant Community”, and add your bot as a member. It needs to be allowed to send messages: members can by default; if you limited them, make the bot an administrator instead. Once the bot is in, the Community group card above shows the group's id under “Detected group”, with a copy button. Upgrading a group to a supergroup (Telegram does it when you add a public link or turn on some settings) changes its id; the card then shows the new one — put it in TELEGRAM_GROUP_ID.
  6. Fill in .env and restart the site: 
    TELEGRAM_BOT_TOKEN=123456789:AA…
TELEGRAM_BOT_USERNAME=YourBotName
TELEGRAM_WEBHOOK_SECRET=<random, see below>
TELEGRAM_CHANNEL_ID=@your_channel      # or -100…
TELEGRAM_CHANNEL_URL=https://t.me/your_channel
TELEGRAM_GROUP_ID=-100…                # from “Detected group”
TELEGRAM_GROUP_URL=https://t.me/+invite_link
SITE_URL=https://your-domain.example
    Make the secret with python -c "import secrets; print(secrets.token_urlsafe(32))" (letters, digits, _ and - only). The group lines are optional; TELEGRAM_GROUP_URL is the invite link students see as “Join our Telegram group”.
  7. Start receiving updates. In production press Register webhook (needs https). On a laptop run python manage.py telegram_bot --poll and leave it running — polling only works while no webhook is registered (--delete-webhook removes one).
  8. Check. Re-check this page: Bot online, Channel and Community group “Can post”. Connect your own Telegram, send yourself a test, then send a test to the channel and to the group. Finally, choose which Automatic alerts go to Telegram.
