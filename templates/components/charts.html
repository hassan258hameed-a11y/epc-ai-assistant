{% comment %} Chart engine — hand-rolled inline SVG, no external library and no network call. Markup contract:
Types: area | bars | donut Two visual languages live here. The default is the one the student app has always used. When a page sets `window.EPC_CHART_THEME = 'console'` before this script runs — base/console_design.html does — the charts switch to the admin console's language: colours read from CSS custom properties, smoothed area curves, pill bars with the peak picked out, and a dark tooltip. Nothing else about the contract changes, so the same markup works on either side. {% endcomment %}
