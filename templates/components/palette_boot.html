{% comment %} The student's colour palette, applied before first paint on every student page — the chat shell and the standalone pages (checkout, receipt, ticket, referrals) alike — so moving between them never changes colour. The design ships six accent pairs and repaints everything from a handful of custom properties. Indigo is the design's own palette: its light and dark shades are tuned in the stylesheet, so choosing it clears any override. The others are derived for the ground they sit on — brighter on dark, deeper on light — until text in the accent clears 4.5:1, and re-derived whenever the theme changes (the chat shell calls ``lumenPalette.apply`` on every change; here the system setting is watched too). {% endcomment %}
