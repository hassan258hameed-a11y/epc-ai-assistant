{% comment %} Decorative motion is a welcome, not a screensaver. Every page has some ambient movement: drifting orbs, sheens across buttons, pulsing dots. Each one is cheap on its own, but running forever they keep the browser repainting while nobody is touching the page, and on an ordinary laptop that is the difference between smooth and laggy. So once the page has been open a few seconds, every *endless decorative* loop is settled: a short one (a sheen, a pulse) finishes the cycle it is on and rests on its natural last frame; a long, slow one (an orb drifting for twenty seconds) simply holds where it is, which no one can tell from rest. Anything that means something keeps going: spinners, the "writing" indicator, a recording, the logo strip, a text cursor — matched by name or by the state class on the element it animates. Mark any other element data-keep-motion to exempt it. {% endcomment %}
